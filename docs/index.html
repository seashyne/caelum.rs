Caelum & mybot-cli Architecture & Tutorial

ระบบเอกสารคู่มือการใช้งาน Caelum High-Performance Rust LLM Engine ร่วมกับ mybot-cli Coding Agent, การเชื่อมต่อ IDE, Tool Calling และการรีดพลัง Intel Arc B580 GPU

⚡ Intel Arc B580 Turbo (128 tok/s) 🦀 100% Pure Rust Engine 🛠️ OpenAI Tool Calling & SSE 💻 mybot-cli TUI Coding Agent 📐 Celestia & Lenout Ready

🚀 เริ่มต้นใช้งาน Caelum ใน 1 นาที

Caelum คือ LLM Inference Engine เขียนด้วย Pure Rust ที่เน้นความเร็วสูงสุด รองรับทั้ง Intel Arc GPU (Vulkan) และ Intel CPU (AVX-VNNI) โดยไม่ต้องพึ่ง Python หรือไดรเวอร์ภายนอกที่หนักเครื่อง

ขั้นตอนที่ 1: ตรวจสอบสถานะฮาร์ดแวร์

ใช้คำสั่ง caelum info เพื่อตรวจสอบว่าระบบตรวจพบการ์ดจอ Intel Arc B580 และคำสั่ง AVX-VNNI ของ CPU หรือไม่:

Terminal 
cd caelum && ./target/release/caelum info

ขั้นตอนที่ 2: ตรวจสอบโครงสร้างไฟล์โมเดล GGUF

คุณสามารถใช้ caelum inspect เพื่ออ่านเมทาดาตา, ขนาดพารามิเตอร์, และประเภท Quantization ในเวลาเพียง 38 มิลลิวินาที:

Terminal 
./target/release/caelum inspect "../models/exported_gguf/llama-3.1-8b-instruct-q4_k_m.gguf"

ขั้นตอนที่ 3: เปิดเซิร์ฟเวอร์ Caelum บนการ์ดจอ Intel Arc B580

สั่งรัน HTTP API Server (มาตรฐาน OpenAI) พร้อมเร่งความเร็วด้วย --gpu:

Terminal (Server) 
./target/release/caelum serve "../models/exported_gguf/llama-3.1-8b-instruct-q4_k_m.gguf" --gpu --port 8000
💡 ทิปการประหยัดแรมบนโหมด CPU
หากต้องการรันบน CPU ให้เอา --gpu ออก แล้วใส่ --kv-q8 แทน เพื่อบีบอัด Key-Value Cache เป็น 8-bit ลดการกิน RAM ลงเกือบ 4 เท่า!

🤖 การใช้งานร่วมกับ mybot-cli (Local AI Coding Agent)

เมื่อจับคู่ Caelum Engine เข้ากับ mybot-cli คุณจะได้สแต็ก AI Coding Agent ที่เป็น 100% Pure Rust ทั้งหมด ทำงานแบบออฟไลน์ 100% ไม่เสียค่า Token และปลอดภัยต่อข้อมูลของคุณ

ขั้นตอนการเชื่อมต่อใน 2 สเต็ป

  1. ตั้งค่า Provider ใน ~/.mybot/config.toml:
~/.mybot/config.toml 
[providers.caelum]
kind = "openai"
base_url = "http://127.0.0.1:8000/v1"
model = "llama-3.1-8b-instruct"
  1. เปิดใช้งาน mybot ในโฟลเดอร์โปรเจกต์ของคุณ:
Terminal 
mybot --model caelum/llama-3.1-8b-instruct

ความสามารถเด่นเมื่อใช้งาน Caelum + mybot

  • Agentic Tool Calling: Caelum รองรับ OpenAI Function Calling เต็มรูปแบบ ทำให้ mybot สามารถสั่ง read, write, edit, และ bash ในเครื่องได้แบบอัตโนมัติ
  • Interactive TUI: หน้าจอเทอร์มินัลสวยงามด้วย Ratatui พร้อม Syntax Highlighting สำหรับบล็อกโค้ด
  • Context Compaction: พิมพ์ /compact เมื่อคุยยาว เพื่อให้โมเดลสรุปบริบทและลดขนาด Session
  • MCP Protocol: รองรับการเชื่อมต่อกับ Model Context Protocol Servers ภายนอกได้ทันที

🔌 การเชื่อมต่อ IDEs, Cline, WebUI และ LM Studio

Caelum ปฏิบัติตามมาตรฐาน OpenAI API Specification 100% จึงสามารถนำไปเชื่อมต่อกับโปรแกรมหรือเครื่องมือพัฒนาซอฟต์แวร์ได้ทันที

1. เชื่อมต่อกับ Cline / Roo Code / OpenCode / Continue.dev

ในหน้าตั้งค่า Provider ของ Extension ใน VS Code หรือ IDE:

ฟิลด์ตั้งค่า ค่าที่ต้องระบุ คำอธิบาย

2. ใช้งานแทน LM Studio Local Server (พอร์ต 1234)

หากคุณมีโปรแกรมที่เคยตั้งค่าเชื่อมต่อกับ LM Studio ที่พอร์ต 1234 คุณสามารถสั่งให้ Caelum รันแทนที่ได้ทันที:

Terminal 
./target/release/caelum serve "/run/media/seashyne/Project/My Artificial Intelligence/Chat AI/LM Studio/Models/lmstudio-community/Qwen3.5-9B-GGUF/Qwen3.5-9B-Q4_K_M.gguf" --gpu --port 1234

3. เชื่อมต่อผ่าน Python (OpenAI Official SDK)

python_client.py 
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="not-needed")

stream = client.chat.completions.create(
    model="llama-3.1-8b",
    messages=[{"role": "user", "content": "เขียนตัวอย่างโค้ด Rust สำหรับ Multi-threading"}],
    stream=True,
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

2. POST /v1/chat/completions (พร้อม Tool Calling)

ส่งคำขอสร้างข้อความ หรือแนบ Tools เพื่อให้โมเดลเลือกเรียกเครื่องมือ:

Request JSON 
{
  "model": "llama-3.1-8b",
  "messages": [
    {"role": "user", "content": "เช็คสภาพอากาศที่กรุงเทพฯ ตอนนี้ให้หน่อย"}
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get current weather for location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": {"type": "string"}
          },
          "required": ["location"]
        }
      }
    }
  ],
  "stream": true

3. POST /v1/celestia/propose (Strict JSON Proposals)

เอนด์พอยต์เฉพาะของระบบ Cetia/Lenout สำหรับบังคับให้โมเดลสร้างผลลัพธ์ตามโครงสร้าง JSON Schema 100%:

curl 
curl http://127.0.0.1:8000/v1/celestia/propose \
  -H "Content-Type: application/json" \
  -d '{"mode": "scene3d", "prompt": "สร้างห้องนั่งเล่นขนาด 4x5 เมตร มีโซฟาและโต๊ะกลาง"}'

⚡ เบื้องหลังความเร็วระดับ Turbo บน Intel Arc B580

ใน Caelum v0.8.0 มีการปรับจูน Kernel และสถาปัตยกรรมระดับฮาร์ดแวร์เพื่อรีดประสิทธิภาพการ์ดจอ Intel Arc B580 (Battlemage G21 12GB) ให้ทำงานได้เต็มขีดจำกัด

1. Subgroup Hardware Ops
ใช้คำสั่ง subgroupAdd และ subgroupMax ของฮาร์ดแวร์ Intel BMG ตัดรอบ workgroupBarrier() ช่วยลด Latency ระดับไมโครวินาที
2. 4-byte-aligned Q6_K
จัดระเบียบบล็อก GGML 210B เป็น 212B (53 u32) ทำให้ GPU โหลด Memory ได้ 100% Coalesced วิ่งเต็มแบนด์วิดท์ 306.4 GB/s (เร็วขึ้น 2.5×)
3. Fused Kernels (-53%)
ฟิวส์ QKV+Bias, SwiGLU FFN, และ Residual+RMSNorm รวมเป็นคำสั่งเดียว ลด GPU Command Dispatches จาก 478 เหลือเพียง 226 ครั้งต่อโทเคน
4. Packed F16 KV Cache
บีบอัด Key-Value Cache บน VRAM ให้เป็น Half-Precision F16 ประหยัดแรมการ์ดจอลง 50% และลด Memory Traffic ขณะ Decode
5. Streaming DMA Uploads
ทยอยส่งข้อมูลเข้าการ์ดจอทีละ 16 MiB พร้อม Per-layer Flush โหลด Llama-3.1 8B เสร็จใน 12.5 วินาที โดยไม่ทำให้ Host RAM บวมหรือแตะ Swap

ตารางเปรียบเทียบประสิทธิภาพบนเครื่องนี้

โมเดลและขนาด Caelum v0.8.0 (Arc B580) llama.cpp Vulkan (LM Studio) การปรับปรุง
Qwen2.5-Coder-1.5B (Q4_K_M) 128.5 tok/s ~45.0 tok/s 2.85× เร็วกว่า
Llama-3.1-8B-Instruct (Q4_K_M) 42.88 tok/s ~20.5 tok/s 2.09× เร็วกว่า
เวลาโหลดโมเดล 8B (Cold Load) 12.5 วินาที ~35.0 วินาที เร็วขึ้นเกือบ 3 เท่า
