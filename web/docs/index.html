Caelum v0.12.0 Architecture & Docs

เอนจิน LLM ภาษา Pure Rust แบบ Zero-Dependency ที่รองรับ Multi-User Continuous Batching, Ultra-Low RAM (GPU 117.7 MB RSS / CPU 62 MB Idle), Split-GGUF, Qwen 3.5, Gemma 4 และการ์ดจอ Intel Arc B580 (Vulkan wgpu)

⚡ Multi-User Continuous Batching 🪶 GPU 117.7 MB RSS · CPU Q4_0/Q8_0 KV 🦀 100% Pure Rust · Split-GGUF 🧠 Qwen 3.5 & Gemma 4 GPU 🛠️ OpenAI Tool Calling & SSE

🚀 เริ่มต้นใช้งาน Caelum v0.12.0 ใน 1 นาที

Caelum คือ LLM Inference Engine เขียนด้วย Pure Rust ที่รองรับทั้งการ์ดจอ Vulkan/Metal/DX12 (`wgpu`), CPU AVX-VNNI/AVX2 และ ARMv9 NEON พร้อม Multi-User Continuous Batching และจัดการ RAM แบบประหยัดสูงสุด

สถาปัตยกรรมภาพรวมของระบบ

⚡
Caelum Engine (caelum/)
รองรับ 13+ สถาปัตยกรรม (Llama, Qwen2/3/3.5, Gemma 2/3/4, Phi-3/4, DeepSeek2, StarCoder2, Mistral, Celestia) ทั้งไฟล์เดี่ยวและ Split-GGUF พร้อม Web Chat & Docs ในตัว
👥
Multi-User Continuous Batching
ประมวลผลหลาย User พร้อมกันระดับ Iteration ด้วย --slots N อ่าน Weight จาก VRAM/RAM รอบเดียวต่อ Step พร้อม Per-Slot KV Prefix Cache
🪶
Ultra-Low RAM (v0.12.0)
คืนหน้า mmap หลังโหลดขึ้น GPU ด้วย MADV_DONTNEED (GPU เหลือเพียง 117.7 MB RSS), Compact Tokenizer, Lazy KV Slots และ --kv-q4 (เล็กกว่า F32 ถึง 7.11×)
💻
Caelum Studio & mybot-cli
ทำงานร่วมกับแอปเดสก์ท็อป Caelum Studio (Tauri), mybot-cli Coding Agent และ My Bot AI Gateway ผ่าน OpenAI API 100%

ขั้นตอนที่ 1: ตรวจสอบฮาร์ดแวร์และโมเดล (รองรับ Split-GGUF อัตโนมัติ)

Terminal 
caelum info && caelum inspect /path/to/qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf

ขั้นตอนที่ 2: เปิดเซิร์ฟเวอร์ Multi-User Continuous Batching (GPU)

เปิดเซิร์ฟเวอร์รองรับ 4 Users พร้อมกัน บนการ์ดจอ Vulkan (ชี้ที่ shard แรกได้เลยถ้าเป็น Split-GGUF):

Terminal (GPU Multi-User Server) 
caelum serve /path/to/model.gguf --gpu --slots 4 --ctx 2048 --port 8000

ขั้นตอนที่ 3: โหมดประหยัด RAM สูงสุดบน CPU

ค่าเริ่มต้นของ caelum serve บน CPU คือ --kv-q8 (3.76× เล็กกว่า F32) และสามารถใช้ --kv-q4 --no-repack เพื่อลด Private Heap เหลือเพียง ~72 MB:

Terminal (CPU Ultra-Low RAM) 
caelum serve /path/to/model.gguf --kv-q4 --no-repack --slots 4 --ctx 2048 --port 8000
💡 RAM-Aware Auto-Repack + Lazy KV Slots
ทุก Slot ที่ยังไม่มีผู้ใช้งานจะจอง RAM เป็น 0 bytes (Lazy Allocation) และระบบจะตรวจ MemAvailable อัตโนมัติเพื่อข้าม CPU Weight Repack หากขนาดโมเดลเกิน 55% ของ RAM ว่าง ป้องกันอาการค้างหรือ Swap Thrashing

🤖 การใช้งานร่วมกับ mybot-cli & Caelum Studio

จับคู่ Caelum v0.12.0 เข้ากับ mybot-cli Coding Agent, Caelum Studio Desktop App หรือ My Bot AI เพื่อใช้งาน AI แบบ Local 100% รองรับหลาย Session พร้อมกัน

เชื่อมต่อ mybot-cli ใน 2 ขั้นตอน

  1. ตั้งค่า Provider ใน ~/.mybot/config.toml:
~/.mybot/config.toml 
[providers.caelum]
kind = "openai"
base_url = "http://127.0.0.1:8000/v1"
model = "qwen2.5-7b-instruct"
  1. เปิดใช้งาน mybot ในโฟลเดอร์โปรเจกต์ของคุณ:
Terminal 
mybot --model caelum/qwen2.5-7b-instruct

ความสามารถเด่นเมื่อใช้งาน Caelum v0.12.0 + Agent

  • Multi-Agent Concurrency: รันหลาย Agent หรือหลายหน้าต่างแชทพร้อมกันบนเซิร์ฟเวอร์เดียวผ่าน Continuous Batching (--slots 4)
  • Agentic Tool Calling: รองรับ OpenAI Function Calling + Real-time SSE delta.tool_calls ไม่มี XML tag หลุด
  • Per-Slot KV Prefix Caching: แชร์ System Prompt และบริบทบทสนทนาซ้ำได้ทันทีโดยไม่ต้องคำนวณ Prefill ใหม่
  • Caelum Studio Desktop: จัดการโมเดล GGUF / Split-GGUF, ดาวน์โหลดจาก Hugging Face, และแชทในแอปเดสก์ท็อป Rust+Tauri

เชื่อมต่อผ่าน My Bot AI Gateway (/api/v1/* + Personal API Key mba_...)

หาก Deploy My Bot AI ไว้บนเซิร์ฟเวอร์ สามารถสร้างคีย์ mba_... ที่หน้า /keys แล้วต่อ mybot-cli จากเครื่องอื่นได้อย่างปลอดภัย:

~/.mybot/config.toml (ผ่าน My Bot AI Gateway) 
[providers.mybotai]
kind = "openai"
base_url = "https://mybot.yourdomain.com/api/v1"
api_key = "mba_YOUR_PERSONAL_KEY"
model = "qwen2.5-7b-instruct"

3. เชื่อมต่อผ่าน Python (OpenAI Official SDK)

python_client.py 
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="not-needed")

stream = client.chat.completions.create(
    model="qwen2.5-7b-instruct",
    messages=[{"role": "user", "content": "เขียนตัวอย่างโค้ด Rust สำหรับ Multi-threading"}],
    stream=True,
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

⚡ Intel Arc B580 GPU Turbo & Ultra-Low RAM (v0.12.0)

สถาปัตยกรรม GPU Compute + Continuous Batching + ระบบคืนหน่วยความจำระดับ OS ที่วัดผลจริงบนเครื่อง Intel Core i5-13400F + Intel Arc B580 12 GB (Vulkan 1.4)

1. Multi-Slot GPU Decode
SHADER_ROPE_KV_STORE_SLOTS_F16 + SHADER_GQA_FLASH_ATTN_SLOTS_F16 + B4 GEMM อ่าน Weight รอบเดียวต่อทุก Active User
2. 2D Row Dispatch (262k Vocab)
กระจาย workgroup แบบ 2D (wid.z * 32768 + wid.x) * 4 ในทุก Matmul Shader รองรับ Gemma 4 vocab=262,144 ภายในลิมิต WebGPU 65,535
3. madvise(MADV_DONTNEED)
คืนหน้า page cache ของ weight 3.56 GB ที่ย้ายขึ้น VRAM แล้วกลับให้ Linux ทันที ลด GPU VmRSS จาก 3,680 MB → 117.7 MB (31.3×)
4. Compact Tokenizer & Lazy KV
ย่อ BPE merges เป็น (u32, u32) + Flat Byte Arena ลด Private Heap ลงครึ่งหนึ่ง และจอง KV Slot แบบ Lazy (0 bytes เมื่อยังไม่ใช้) + โหมด --kv-q4 (7.11× เล็กกว่า F32)
